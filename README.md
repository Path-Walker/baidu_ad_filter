# Baidu Ad Result Filter

一个用于 Chrome / Edge 的 Manifest V3 浏览器插件。它会在百度搜索结果页隐藏带有“广告”“推广”“商业推广”等标签的结果，只保留普通搜索结果。

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展”。
4. 选择本目录：`~\baidu-ad-filter`。

## 使用

打开 `https://www.baidu.com/s?wd=关键词` 后插件会自动扫描页面。点击工具栏插件图标可以开关过滤、关闭右下角提示，或手动重新扫描当前页。

## 过滤逻辑

插件不会请求外部服务，也不读取搜索关键词。它只在当前百度结果页的 DOM 中查找搜索结果块，并隐藏包含短标签文本的结果，例如：

- `广告`
- `推广`
- `商业推广`
- `百度推广`
- `赞助`
- `Sponsored`

如果百度调整页面结构，可以优先修改 `content.js` 里的 `RESULT_SELECTORS` 和 `AD_LABELS`。
